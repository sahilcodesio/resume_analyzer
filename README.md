# Resume Analyzer

A Python-based Resume Analyzer that helps users evaluate their resumes by comparing them with job descriptions and providing useful feedback.

## Features
- Upload resume (PDF)
- Analyze resume content
- Compare with job descriptions
- Generate suggestions for improvement
- Simple and user-friendly interface

## Tech Stack
- Python
- Streamlit
- PyPDF2
- NLP

## Installation

```bash
git clone https://github.com/sahilcodesio/resume_analyzer.git
cd resume_analyzer
pip install -r requirements.txt
streamlit run app.py
```
